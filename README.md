# Crypto Watcher PRO v0.2

Україномовний Android-застосунок для моніторингу публічних адрес у п'яти мережах: Bitcoin, Ethereum, BNB Smart Chain, Polygon та Solana.

## Реалізовано
- Додавання та локальне збереження публічних адрес.
- Отримання нативного балансу через публічні API/RPC.
- Видалення адрес і ручне оновлення балансів.
- Український інтерфейс.
- Seed-фрази та приватні ключі не запитуються.

## Збірка
GitHub Actions збирає debug APK після push у main або вручну через Actions. APK буде доступний як artifact у запуску workflow.

Це тестова debug-збірка, не production-реліз із підписаним ключем.

## Ще не реалізовано
Токени ERC-20/BEP-20/SPL, історія транзакцій, push-сповіщення та графіки. Публічні RPC можуть мати ліміти або тимчасово бути недоступними.
